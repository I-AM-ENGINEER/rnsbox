Connect an app to this box

  1. Plug RNSBox into your computer with USB-C — your OS gets a new network connection (the box is 10.42.0.1).
  2. Open MeshChat (or Sideband). It usually auto-discovers the box over the USB link — nothing to configure.
  3. To add it by hand: add a TCP Client interface → Host 10.42.0.1, Port 4242.
  4. You're on Reticulum. (NomadNet is also already on the box — SSH in as root/admin and run nomadnet.)
