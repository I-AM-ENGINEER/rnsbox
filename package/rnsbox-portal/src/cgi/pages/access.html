How issued key files work

Issuing mints a fresh Reticulum identity, adds its public hash to the allow-list above and returns a plain-text file with the private key and ready-to-paste Linux instructions (pip install rns, then rnsh -i <key> <destination>). The private key exists only in that download; a lost file cannot be re-downloaded — use Revoke & re-issue.
