Remote access — issued key files

Issuing an access mints a fresh client identity, adds its public hash to the rnsh allow-list above and downloads a plain-text file with the private key and ready-to-paste Linux instructions (pip install rns, then rnsh -i <key> <destination>).

The private key is never stored on the box — the downloaded file is its only copy. Save it immediately; a lost file cannot be re-downloaded, use Revoke & re-issue. Revoking makes the old file useless.

POST — responds with text/plain download; do this from a trusted network.
