Remote access (rnsh) — Удалённый доступ

A root shell on this box, reachable from anywhere on the Reticulum network. Issuing an access mints a fresh client identity, adds its public hash to the rnsh allow-list and downloads a plain-text file with the private key and ready-to-paste Linux instructions (pip install rns, then rnsh -i <key> <destination>).

The private key is never stored on the box — the downloaded file is its only copy. Save it immediately; a lost file cannot be re-downloaded, use Revoke & re-issue. Revoking makes the old file useless. The allow-list itself is shared with the manual RNS Shell card on the Reticulum tab.
