RNS Shell (rnsh)

A root shell reachable from anywhere on the Reticulum network. Client: pip install rnsh, rnsh -p prints your identity hash (goes into the allow-list below), then rnsh <destination> and disconnect with ~. Authentication is by that allow-list only — the service refuses to start with an empty one. Off by default.
