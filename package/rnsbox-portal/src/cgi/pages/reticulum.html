HaLow modem (SLIP)

Optional point-to-point serial link (sl0) to an external WiFi-HaLow RNode modem over a UART. When the modem is reachable, the Add to rnsd config button below routes Reticulum through it (a TCPClientInterface named after the modem's hostname). Off by default.

Link (sl0) __SLIP_LINK_STATUS__
__HALOW_LIVE_BLOCK__

Wire the hardware UART (GPIO14 TX = physical pin 8, GPIO15 RX = pin 10, 3.3 V) to the modem, cross TX↔RX, common ground — device /dev/serial0. Bluetooth is disabled and the serial console kept off the UART so the port is free. Baud must match the modem — 2 Mbaud (the modem default; the PL011 handles it) is pre-filled. The IPs must match the modem's SLIP config (defaults 192.168.7.2 modem / 192.168.7.1 box).
