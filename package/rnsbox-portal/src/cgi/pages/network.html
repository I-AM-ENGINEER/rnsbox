Default uplink

Which interface reaches the internet, and how it gets its address. The forwarding rules and the open ports follow this choice. Automatic (the default) uses eth0 while it has a cable and an address and the WiFi client otherwise, switching by itself when the cable goes in or out. eth0 or wlan0 pins the uplink to that one interface; the box never changes your choice. The WiFi client needs to be connected (WiFi tab → mode sta or sta+ap) and is always DHCP-addressed by the WiFi stack — the static fields below apply to eth0 only.

Port forwards (Ethernet → USB-NCM)

Inbound TCP/UDP traffic arriving on the Ethernet side is DNAT'd to the USB-NCM host:port. The matching FORWARD rule is added automatically.

Open ports (services exposed on Ethernet)

Allows inbound connections on the Ethernet side to services bound on this device. SSH (22), the web UI (80) (which also carries the HaLow modem page on 8081) and rnsd's TCPServerInterface (4242), for external Reticulum peers, are open by default — remove them to close Ethernet access (the USB-NCM side — __LAN__: the USB-C link, plus the WiFi hotspot while it is on — always stays open).
