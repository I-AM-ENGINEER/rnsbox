Default uplink

The interface that reaches the internet; the forwarding rules and the open ports follow this choice. Automatic (recommended) uses the wired link while it has a cable and an address and falls back to the WiFi client, switching by itself when the cable goes in or out. Pinning one interface means the box never switches on its own. The WiFi client must be connected (WiFi tab → mode sta or sta+ap) and is always DHCP-addressed by the WiFi stack, so the static fields below apply to Ethernet only.

Port forwards (WAN → LAN)

Inbound TCP/UDP traffic arriving on the WAN side is DNAT'd to a LAN host:port. The matching FORWARD rule is added automatically.

Open ports (services exposed on Ethernet)

Allows inbound connections on the WAN side to services bound on this device. SSH (22), the web UI (80) (which also carries the HaLow modem page on 8081) and rnsd's TCPServerInterface (4242), for external Reticulum peers, are open by default — remove them to close WAN access (the LAN side — __LAN__: the USB-C link, plus the WiFi hotspot while it is on — always stays open).
