Whole-OS (A/B slot) updates from a repository you choose. The box checks on a random 7–14 day schedule, so a fleet of routers never phones home in sync. Applying writes the idle rootfs slot and flips to it on reboot — the old slot is kept, and the box rolls back by itself if the new one fails to boot healthy within three tries. Layout not A/B? Flash any current image once — updates work over the air after that.
