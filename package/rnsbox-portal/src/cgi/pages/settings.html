Hardware clock__RTC_STATUS__

Reticulum (and nomadnet/lxmd when enabled) runs whatever the clock says — no internet needed; a correct clock just keeps timestamps meaningful. At boot the time comes from the hardware clock (RTC) when one is fitted and set; NTP takes over whenever a time server is reachable, and every NTP or browser sync is written to the RTC (and, while a time server is reachable, the NTP time once an hour).

Sync to browser

Set the clock to this device's time — the quickest way to get a correct clock on a box with no internet (HaLow-, USB-NCM- or WiFi-only). A fitted RTC is set too, even one that was never set, so the time survives reboots.

SSH

Status__SSH_STATUS__

SSH is off by default. When enabled it serves the USB-NCM link (USB-C gadget, WiFi hotspot) — the Ethernet side stays closed unless tcp 22 is also added to Open ports on the Network tab. The login is the unprivileged user admin; root login is closed.
