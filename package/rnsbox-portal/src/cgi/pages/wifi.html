Modes

Both modes can be enabled at once — the single radio time-shares them. With both off the radio is idle: that is a normal operating state, not an error.

STA mode — join a network

__STA_OFF_NOTE__
SSIDSignalChBandSecurity
__CONCURRENT_NOTE__

Another RNSBox's hotspot can't be this box's uplink: every RNSBox's LAN is 10.42.0.0/24, so the box refuses DHCP from such a network (its router and DNS would be the box itself).

AP mode — hotspot

__AP_OFF_NOTE__ __AP_PSK_NOTE__

Clear the field to let the hotspot follow the device hostname (it shows the current name — __AP_SSID__ — and follows S10uuid's rename); typing a name pins it.

The hotspot ships with no password and stays off until you choose one: 8–63 printable ASCII characters, without # or ". The old published default changeme123 is refused.

In concurrent STA + AP mode the client follows the hotspot's band and the hotspot inherits the client's exact channel and width (single radio — they must share one channel). auto channel and manual width changes apply only in AP-only mode; if the radio can't honor them the hotspot falls back to 20 MHz.

TX power

Radio-wide — applies to both client and hotspot (single radio). auto = chip maximum, independent of the regulatory database. A number caps power; firmware still applies per-rate EVM backoff below it. Set lower to cut heat/range.
