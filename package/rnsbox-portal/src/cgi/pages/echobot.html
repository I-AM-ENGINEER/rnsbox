Try it from any LXMF client

NomadNet: Conversations → enter the LXMF address above → send any text — the bot echoes it right back. Sideband and every other LXMF client work the same. The announce carries the bot's name, so once heard, it also shows up in NomadNet's node list. Announce history: logread | grep echobot.

The bot shares rnsd's Reticulum instance and has its own persistent identity: its address and name suffix never change across reboots or updates. It coexists with lxmd and NomadNet — each holds its own LXMF destination.

Settings

Saving restarts the bot (or stops it when disabled). A start is refused while free RAM is below min_free_mb (40 MB) in /etc/rnsbox/echobot.conf — that floor protects rnsd from the OOM killer; free RAM first (or lower the floor if you know your budget) and start again.
